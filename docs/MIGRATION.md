# Migration from Island or Insular

Harbor has a new application ID and signing identity. It cannot update Island or Insular in place and cannot unilaterally take ownership of their work profiles.

Before migrating, record the applications and data needed from the existing work profile. Removing that profile permanently deletes its applications and data. Remove the Island/Insular profile through Android Settings, install Harbor from F-Droid, then create a new Harbor work profile and reinstall applications inside it.

Android ownership transfer would require a cooperating release from the current source DPC and is not part of Harbor's migration path.
