# Privacy policy

Harbor does not collect, transmit, sell, or share personal data.

Harbor has no network permission and contains no analytics, advertising, crash-reporting, account, or remote-configuration SDK. It reads the local application list to provide its app-management function. Optional Shizuku diagnostics read local Android user and package-manager state only after the user enables Advanced tools and grants Shizuku permission.

Diagnostic results remain on the device. This release does not automatically upload or export them.

Android, an OEM, F-Droid, Shizuku, and applications installed inside a work profile have their own privacy behavior and are not operated by Harbor.
