# Harbor 0.2.0-alpha03

This alpha makes personal-to-work file import explicit and reliable through Android's supported share and document-picker APIs.

## Highlights

- Adds `Pick from personal files` in the work-profile Harbor UI.
- Adds a Share target that copies granted `content://` files into work-profile `Downloads/Harbor` without deleting personal originals.
- Replaces Harbor-owned cross-profile filters idempotently when the sharing action is repeated.
- Separates file import, APK installation, and work-profile app management into distinct UI sections.
- Explains that OEM-specific `Move to work` actions may remain blocked even when Android Share is enabled.

## Security and compatibility

- No hidden APIs, reflection, arbitrary shell, network access, telemetry, or new heavy dependencies were added.
- Harbor only accepts explicitly granted content URIs and never deletes the personal source file.
- The work-profile Harbor instance must be updated for the profile-owner policy to change.

## Validation

- JVM tests, debug lint, release assembly, SBOM generation, manifest audit, and reproducibility checks pass.
- Physical validation remains required on Pixel Android 16, Android 10 hardware, Samsung, Xiaomi, another OEM, and a GMS-free device.
