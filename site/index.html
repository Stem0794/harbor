What Harbor does

Keep Work apps separate and under control.

01

Create a Work profile

Use Android's supported managed-profile flow. No root or hidden APIs are needed for the normal path.

02

Manage Work apps

Launch, freeze, unfreeze, inspect, uninstall, and create shortcuts for apps inside Work.

03

Send files into Work

Copy selected files from Personal into Downloads/Harbor inside the Work profile.

Privacy by architecture

Local by default.

Harbor's core app does not request Android's INTERNET permission. There is no account system, analytics SDK, advertising, Firebase, or remote configuration.
