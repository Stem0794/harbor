Built for isolation

A focused manager for your Work space.

Harbor keeps the normal path simple: provision the profile, manage its apps, and let Android enforce the boundary.

Create an isolated Work space

Use Android's standard managed-profile flow. Apps in Work get their own app data and Android's work badge.

Conservative by design

Harbor avoids hidden APIs and unsafe profile guessing. Ambiguous privileged operations fail closed.

Optional advanced tools

Shizuku can add diagnostics, package cloning, user discovery, and experimental additional workspaces.

Privacy by architecture

Local by default.
No cloud layer.

Harbor's core app does not declare Android's INTERNET permission. It has no analytics SDK, advertising, account system, Firebase, or remote configuration.

How it works

Two Harbor instances.
One Android boundary.

The same APK runs on both sides. The Work copy becomes profile owner and performs policy actions inside the managed profile.

Compatibility

Android 10 through Android 16.

Harbor targets API 29–36. Work-profile and device-policy behavior can still vary by manufacturer, so real-device reports matter while Harbor is alpha.
